ANTES DE EMPEZAR

Las dudas,
resueltas.

¿Qué necesito para usar Gema?+

Windows 10 u 11 de 64 bits y espacio para el modelo que elijas. No necesitas una GPU NVIDIA: Ollama puede usar CPU o una GPU compatible. Los modelos pequeños son más adecuados para equipos con poca memoria; la biblioteca muestra estimaciones y recomendaciones según tu RAM.

¿Funciona sin Internet?+

Necesitas conexión para instalar el motor, preparar WebView2 si falta y descargar modelos. Después, el chat y las herramientas locales pueden funcionar sin Internet. Buscar actualizaciones consulta la web de Gema.

¿Mis conversaciones y archivos se envían a una nube?+

Gema envía los mensajes y el contexto de archivos al motor local de Ollama, en tu propio PC. La comprobación de versiones no incluye chats ni archivos. Una prueba del proyecto autorizada por ti ejecuta código con tus permisos y puede acceder a Internet.

¿Gema modifica mis archivos automáticamente?+

No. Programar prepara propuestas: abre sus tarjetas, revisa las diferencias y elige qué aplicar. Revisar y Planificar trabajan en modo lectura. Cada ejecución de pruebas requiere autorización.

¿Puedo dejar un proyecto trabajando mientras abro otro?+

Sí. Cada chat mantiene su propio trabajo y puedes navegar entre proyectos o minimizar Gema. El motor organiza las generaciones en una cola para limitar la memoria. Salir por completo detiene los trabajos; no continúan con el PC apagado.

¿Actualizar borra mis chats o los modelos?+

El instalador actualiza la app en su ubicación actual. Conserva los chats, proyectos, ajustes y modelos, y guarda una copia del perfil. Las versiones anteriores a la 0.2.7 se actualizan ejecutando el instalador de esta página.

¿Es el asistente de voz de QuickDeck?+

Esta Gema es una aplicación de chat y agentes independiente. Tiene su propio perfil y no cambia el asistente de voz ni los datos de QuickDeck.
